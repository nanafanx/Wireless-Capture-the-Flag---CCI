# Wireless-Capture-the-Flag-CCI
This GitHub repository is for **Wireless Capture the Flag**.

**Download the ZIP file for access to the challenges.**

A write-up file is provided. Please attempt the challenges on your own before reading the write-up.

Wireless Capture the Flag is a beginner-friendly CTF that is designed to introduce students to wireless technology, signal analysis, and cybersecurity concepts in an interactive way.
